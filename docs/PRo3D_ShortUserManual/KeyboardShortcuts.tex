\paragraph{The modifier key: Ctrl, or Cmd on macOS.}
Wherever this manual says CTRL (CTRL+LMB to pick, ctrl s, ctrl z, \ldots), use \textbf{Cmd}
on macOS: there CTRL+click is a right-click. Both Cmd keys work. \textbf{Alt} (\textbf{Option} on
macOS) is \emph{not} a substitute for CTRL: until this version it acted as one, so Alt+click
picked and Alt+S saved; now Alt only does what a tool says it does (for example the toggle of a
box selection, CTRL+Alt+drag). If PRo3D loses focus while CTRL is held (Cmd+Tab, Alt+Tab), it
treats CTRL as released. See \onlinedoc{DirectToolMode.md}{DirectToolMode.md}.
