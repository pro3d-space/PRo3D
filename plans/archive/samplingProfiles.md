the goal of this stage is to sample points along the drawn line. so, given a sampling distance x, we need to find points on the surface along the drawn line. for testing this should be integrated in the line drawing. each time a new point is added to the line, perform the sampling for the new segment and accumulate the sampled points in an array (in a cval) and render it using Sg.spheres or something like this.

to accomplish this, we need to shoot rays along the drawn line to find the exact hits for each sampling point. to accomplish this we need to know the direction "into" the object. to accomplish this, the normal vector needs to be computed. 
so for each point of the drawn line, we first need to compute the normal vector. to this end, by taking the index of the hit hit.SetObject.Index (we prepared for this) and loading the vertex data of the patch. so first we need to find the triangleset associated with this kdtree. for this please consult "C:\Users\haral\Desktop\aardvark\OpcViewer\src\OPCViewer.Base\KdTrees.fs" and maybe C:\Users\haral\Desktop\pro3d\pro3d-6\src\PRo3D.Viewer\Viewer\Picking.fs (maybe other parts on pro3d code help as well). potentially we also first need to read the patch data (PRo3D.Core.Surface.DebugKdTreesX.loadTriangles' is a good starting point)
